# Development Archive

This directory preserves the project's detailed implementation plans, prompt notes, and historical
code review. They document how Chef Human evolved, but they are not the current product documentation
or an implementation queue.

- `plans/original-roadmap.md` is the original broad roadmap.
- `plans/plan_*.md` are implementation journals for individual development phases.
- `reviews/` contains point-in-time reviews whose findings must be re-verified against current code.
- `prompts.txt` records historical agent instructions.

Current product and implementation planning lives in [`../finish-line/`](../finish-line/README.md).
The public installation and usage documents live one directory above this archive.
